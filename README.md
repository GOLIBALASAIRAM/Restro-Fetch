# Restro-Fetch

Tech Stack: SQL, Flask (Backend), React (Frontend)

Description:
Restro Fetch is an intelligent restaurant discovery web application that allows users to explore and filter a curated list of restaurants using various criteria. The backend is built with Flask and SQL, while the frontend is powered by React, ensuring a responsive and interactive user experience.

Key Features:

Geolocation Filtering: Search restaurants by specifying latitude and longitude.

Name Search: Easily find restaurants by typing their names.

Cuisine-Based Filtering: Filter restaurants based on the most popular cuisines they offer.

Price Range Selection: Narrow down restaurants within a specific budget range.

Image/File Upload: Upload a cuisine image or file to get matching restaurant suggestions.

Purpose:
To simplify the restaurant search process with smart filters and user-friendly input options, providing functionality similar to platforms like Zomato.
